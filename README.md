#Odin Project

ESTE PROJETO É UM SITE DE RECEITAS DESENVOLVIDO EM HTML PARA COLOCAR EM PRÁTICA OS CONCEITOS FUNDAMENTAIS DE DESENVOLVIMENTO WEB, aprendidos no The Odin Project.

## Habilidades praticadas:
- Estrutua base do HTML
- Elemento de texto,listas e imagem
- Links de navegação entre páginas
- Controle de Versão com Git e Github
